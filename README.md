## 投稿前准备

- 产品名称、官网、Mac App Store 或官方下载链接，以及一句话介绍。
- 方形 PNG 图标、至少两张实际应用截图，以及截图的公开 HTTPS 链接。
- 最低 macOS 版本、Apple silicon / Intel 支持、定价与内购说明、更新日志。
- 可收取验证邮件的联系地址。选择徽章档前，先确认能编辑产品官网。
- 先在目标站内搜索产品名称或网址。记录是否已提交、待验证、审核中或已公开。

## 补充条目

欢迎用 GitHub Issue 或 Pull Request 补充、纠错。请提供平台名称、投稿入口、适用应用、免费或付费条件、账号或徽章要求、官方说明链接及核对日期。若入口只在登录后可见，注明你核对到的步骤即可。已有产品的私人投稿状态和登录资料不属于本目录。
